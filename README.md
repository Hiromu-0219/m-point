# M-POINT

麻雀卓の中央にスマートフォンまたはタブレットを置いて使う、4人麻雀用の点数表示・点数移動PWAです。

## 起動

Node.js 22.13以上を用意し、次を実行します。

```bash
npm install
npm run dev
```

画面に表示されたURLを開き、端末を横向きにして卓の中央へ置いてください。

## 主な操作

- 各プレイヤー領域をタップ: リーチ宣言（1,000点減算・供託追加）
- 中央の「点数移動」: ロン/ツモ、和了者、放銃者、翻、符を選択して確定
- 「履歴」: 操作履歴を表示
- 「1手戻す」: 直前の状態へ復元
- 「リセット」: 25,000点持ちへ戻す（Undo可能）

状態はブラウザのLocalStorageに保存され、再読み込み後も復元されます。外部API・認証・クラウド同期は使用しません。

## 点数計算

一般的な日本式リーチ麻雀の計算式を使用します。支払いは100点単位で切り上げ、3翻70符・4翻40符・5翻は満貫、6〜7翻は跳満、8〜10翻は倍満、11〜12翻は三倍満、13翻以上は役満です。切り上げ満貫は採用していません。
